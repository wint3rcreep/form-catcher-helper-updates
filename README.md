# Callibri Form Catcher Helper — обновления для Firefox

Публичный репозиторий **только для артефактов автообновления**. Исходный код расширения живёт в приватном репозитории `zedf0r/form-catcher-helper` (ветка `firefox`) и здесь не публикуется.

Содержимое обновляется автоматически из CI приватного репозитория при каждой новой подписанной сборке.

## Что здесь лежит

| Файл | Назначение |
|---|---|
| `updates.json` | Update manifest для Firefox. Его URL прописан в расширении как `update_url`. |
| `releases/form-catcher-helper-<version>.xpi` | Подписанные в AMO сборки. Старые версии не удаляются: на них могут ссылаться прежние записи манифеста. |

## Как это работает

Расширение распространяется вне addons.mozilla.org (канал `unlisted`), поэтому Mozilla обновления не раздаёт — их нужно хостить самостоятельно. Firefox периодически запрашивает `updates.json` **без авторизации**, сравнивает поле `version` с установленной и, если версия выше, скачивает `update_link`.

Поэтому репозиторий должен быть публичным: из приватного GitHub отдавал бы `404`, и обновление молча не устанавливалось бы.

## Установка расширения

Скачать последний `.xpi` из `releases/` и открыть его в Firefox: перетащить в окно браузера либо `about:addons` → ⚙ → **«Установить дополнение из файла…»**.

Сборки подписаны в AMO, поэтому ставятся в обычный Firefox. После установки обновления приходят автоматически.

## Важные нюансы

- Firefox сравнивает версии **только** по числовому полю `version`. Отображаемая метка (например `3.10.2b`) хранится в `version_name` и в сравнении не участвует.
- Каждая уходящая в подпись сборка обязана иметь новую `version` — AMO отклоняет повторную подпись существующей версии.
- Копии расширения, установленные до появления `update_url`, обновления проверять не начнут: их нужно один раз переустановить вручную.
- Ссылки обязательно по HTTPS, иначе Firefox откажется применять обновление.
